# Todo
## About
<p>
    Its a todo webpage that allows the user to make there own task list and diaries, the user can see only there own tasks/diarys.
</p>
<p>
    Built with Laravel.
</p>

## Features
<ul>
    <li>
        Createing/editing/deleting Tasks
    </li>
    <li>
        Createing/editing/deleting Diary
    </li>
    <li>
        To mark a task done or not done you need to check the box thats has the text "Is the task completed" next to it  in the edit page
    </li>
</ul>
